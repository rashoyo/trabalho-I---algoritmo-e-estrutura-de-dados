# CRUD - Gerenciador de Pontuação de Jogos

Trabalho prático da disciplina de Algoritmo e Estrutura de Dados.

## Sobre o Projeto
Programa desenvolvido em linguagem C para registrar, gerenciar e analisar históricos de pontuações de partidas utilizando vetores, estruturas condicionais (`if/else`), laço `for` e `do-while`.

## Funcionalidades
1. Registrar nova pontuação
2. Ver placar e total acumulado (com exibição do total e média)
3. Buscar se atingiu uma pontuação específica
4. Corrigir pontuação existente
5. Remover última pontuação
6. Sair
